## 1. 段落切分规则（关键）

原文排版是「一句一行」，平均 143 行/章。**绝不可按行切段**。按**场景段**切：

| 切分信号 | 说明 |
|---|---|
| 时空跳转 | 地点/时间标记句（"此时。""三日后。""镜头一转。"） |
| 视角切换 | 主角在场 → 他者视角（围观群众/官方/敌人） |
| 功能切换 | 打斗 → 结算面板 → 吐槽 → 新悬念 |
| 对话群 | 一场连续对话为一个段 |
| 面板/系统弹窗 | 独立成段（面板本身信息量大） |

- 单章 **4–6 段**；短章可 3 段，长章最多 7 段。
- 编号 `章号-段号`，章号为**全局章号三位数**（如 `004-01`），段号两位。
- 每段必须给**段界锚点**：该段**首句的前 4–8 个字**，用「」包裹，供回原文复核。

## 2. 每章必须先给「章级总览」

```
## 章级总览

| 项 | 内容 |
|---|---|
| 体量 | 1,600 字符，5 段 |
| 本章功能 | 一句话定性 + 2–3 句展开：本章在全书/本卷推进了什么 |
| 节奏曲线 | 用 → 连接 4–6 个节拍词（如：静→紧→爆→断） |
| 主要写法 | 3–6 个已命名技法，用、分隔 |
| 视角 | 谁的眼睛，是否越界 |
| 章末钩子 | 引末句关键词 + 说明钩子类型 |
```

| **6 文笔/写法** | …… |

### 各字段质量标准与字数

| 字段 | 要求 | 字数 |
|---|---|---|
| 2 摘要 | 连贯 2–5 句，写清"谁—做了什么—结果如何"，不遗漏关键因果；信息密度高可加句 | 120–220 |
| 3 功能 | 命名功能（铺垫/冲突升级/信息释放/转折/人物揭示/节奏缓冲/世界观补完/战力校准/喜剧换气…）并说明服务于什么 | 60–120 |
| 4 行为—剧情连接 | 严格写「行为→动机→后果」，禁止只复述情节；后果分外部（剧情推进）与内部（心理/关系变化） | 80–160 |
| 5 冲突与悬念 | 推进或制造了什么冲突、悬念、信息差、读者期待；无冲突时说明"张力由什么替代" | 50–110 |
| 6 文笔/写法 | **必须给技法命名**（见 §4 词表），并说明句法/节奏/视角/修辞/情绪上的具体特征与效果 | 80–160 |
| 7 使用时机 | 具体写作场景（开篇/转场/冲突前/高潮/收束/人物出场/设定交付…），至少 2 条 | 40–90 |
| 8 避免时机 | 什么场景慎用 + **原因** | 40–90 |
| 9 可迁移模板 | 抽象公式，用 → 连接，**不得抄原文句子** | 60–120 |
| 10 风险提示 | 模仿时的具体失败模式（拖沓/视角混乱/情绪过载/信息倾泻/人设漂移…） | 40–80 |
| 11 关键词 | 3–6 个，供检索：人名、地名、物件、母题、动作（如 承诺、背叛、雨夜） | — |
| 12 情绪基调 | 2–4 个词 + 强度（如"憋闷中带滑稽，中强度"） | 8–20 |
| 13 关联段 | 2–4 个真实存在的段 ID：伏笔—回收、因果、镜像、对照关系 | — |

## 4. 技法命名词表（优先取用，可自创但须同样具体）

冷开场／数字锚定／信息延迟／视角切换／他者称重（借旁人侧写测强度）／面板插入／规则说明书／
短句压迫／长句铺陈／断句收束／对话夹叙／环境映衬／反讽降格／自嘲旁白／梗化注解／
留白／错位期待／双线并置／倒叙楔子／重复变奏／物件锚（同一物件反复出现承载意义）／
数据简报体／法医式验尸（用第三方专业流程反证强度）／群像快切／章末双钩／标题反讽。

## 5. 铁律

1. **一切判断须有文本依据**。可短引关键词（≤12 字，加引号），**禁止大段复述原文**。
2. 不写读后感、不写"生动""优美""有感染力"这类空词。
3. 区分「文本描述」（书中实际怎么写）与「调用建议」（何时可用/何时避免），不得混为一谈。
4. 无法判断时写"文本依据不足"，**不许编造剧情**。
5. 人名、境界、数值必须与原文一致；不确定就回原文核。
6. 表格单元格内**不得出现半角竖线 `|`**，需要时用 `｜`。
