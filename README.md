# webnovel-analysis-and-creation (网文深度拆解与创作项目)

> **项目定位**：本项目是一个面向网络文学（仙侠、修真、文道等题材）的**工业级深度拆解、剧情工程化台账、创作技法库与 AI 辅助写作实践工坊**。
>
> 涵盖两部代表性百万字级网文巨作的底层工程拆解全貌，以及基于拆解成果衍生的高武都市仿写创作实践，为人类创作者及面向剧情创作的 AI Agent 提供细粒度、结构化、可复用、可检索的参考资产。

## 三、 Agent 消费与调用指南

为了让大语言模型（LLM）或智能体在参与本项目的分析或创作时以最低 Token 消耗获取最高信息密度，建议遵守以下原则：

1. **避免一次性加载大文件**：
   * `00_承接链.md` (4.6 MB) 和 `02_伏笔台账.md` (1.2 MB) 严禁全局读取；请优先通过正则匹配、行号定位或检索特定章节标记（如 `### 第0128章`）。
2. **三步精准命中法**：
   * **查宏观线索** $\rightarrow$ 先读 `00_全书总索引.md` / `03_全书汇总报告.md` / `00_交付清单.md`
   * **查人物与伏笔** $\rightarrow$ 读取 `04_全景人物志.md` / `05_伏笔终极回收表.md`
   * **查微观场景与技法** $\rightarrow$ 读取对应 `第XXXX章_解析.md` 或通过 `32_查询手册_技法库与调用总清单.md` 反查段级 ID。
3. **查阅根目录专属指南**：
   * 详细的 Agent 使用说明请直接参阅：[AGENTS.md](AGENTS.md)。

## 四、 规范与设计哲学

- **工程化（Engineering）**：将文学创作中抽象的灵感拆解为具象的“冲突参数”、“信息落差”、“情绪曲线”和“伏笔节点”。
- **可复现（Reproducible）**：每一个拆解出的段落均带有锚点与原始段界，支持随时回链对照。
- **模块化（Composable）**：所有技法均提炼成独立的卡片与模板，创作时可如搭积木般组合拼装。
