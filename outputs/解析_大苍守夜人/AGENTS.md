## 二、 Agent 六大高频调用场景与最佳路径（Recipes）

在处理与《大苍守夜人》相关的查询、分析、创作或问答时，Agent 应根据具体需求选择**最轻量、最精准**的读取路径：

### 场景 1：精准查询某一章节的情节 / 场景 / 战斗 / 对白
* **目标**：快速获取某章写了什么、在场人物、冲突动作或结尾钩子。
* **最佳路径**：**直接读取 `章节/第XXXX章_解析.md`**（四位数字对齐，如 `第0048章_解析.md`）。
* **优势**：每篇单章解析均严格遵循固定的八节结构（①本章定位 ②剧情梗概 ③场景与事件序列表格 ④人物动作与动机 ⑤冲突与悬念 ⑥章末钩子 ⑦剧情走向 ⑧承接关系），无需通读上万字原文即可毫秒级提取精准事实。

### 场景 2：追溯跨多章的剧情上下文 / 快速梳理连续剧情链
* **目标**：了解主角在某一段连续章节（如 0120～0130 章）中的位置转移、行动线索或状态变动。
* **最佳路径**：**检索 `00_承接链.md`**。
* **读取策略**：通过行区间或关键词搜索定位 `### 第XXXX章` 承接块。每个承接块仅 6～8 行（时地、主线、人物、新伏笔、回收、章末状态），信息高度浓缩，极度节省上下文 Token。

### 场景 3：查询人物身份、情感脉络、平妻名单与终极归宿
* **目标**：确认主角林苏身边的红颜知己、后宫名单、大婚位次、朝堂兄弟（如姬广、章浩然）或剑修知己（独孤行、李泽西）。
* **最佳路径**：**直接读取 `04_全景人物志.md`**。
* **核心内容**：收录了第 1292 章除夕大婚官方实证的平妻出场顺序（暗夜 $\rightarrow$ 向惊鸿 $\rightarrow$ 陈姐 $\rightarrow$ 绿衣 $\rightarrow$ 元姬 $\rightarrow$ 崔莺 $\rightarrow$ 秋水画屏……凤随心 $\rightarrow$ 李归涵等共 29 位），以及朝堂君臣与反派谱系。

### 场景 4：追踪伏笔、暗线解密与谜团真相
* **目标**：了解定远侯冤案真相、枯树识海本质、为何千年无词道、四重守夜人演进、龙儿开花等。
* **最佳路径**：
  * **宏观核心暗线**：优先查阅 **`05_伏笔终极回收表.md`**（已提炼十大核心暗线的起承转合与终局闭环）。
  * **微观具体伏笔**：定位查阅 **`02_伏笔台账.md`**（开头 40 行为重点跟踪表，后续为具体 ID 的在办与回收明细）。

### 场景 5：全书宏观世界观、力量体系、主线分卷历史
* **目标**：需要全书的宏观战力分级（文道/武道/修真）、主线四大演变阶段或文学艺术评价。
* **最佳路径**：读取 **`03_全书汇总报告.md`**（世界观与战力）、**`01_主线状态.md`**（17个分卷篇章的历史梳理）与 **`00_全书总索引.md`**。

### 场景 6：番外解析、守夜人宇宙第二部与《现代版荒古神话》
* **目标**：探究全书完结后的现代篇延展、主角林小苏、石头天窗机制与现代唯物主义解构仙术。
* **最佳路径**：读取 **`06_番外与现代版荒古神话.md`**。

## 三、 Agent 行为守则与安全红线（Guardrails）

1. **只读消费原则（Read-Only Consumption）**：  
   本目录中的 1293 篇单章解析、承接链及全书研报均为全书完结后的**终审交付物**。作为知识库消费端，Agent **严禁擅自修改、删除或覆写**核心 Markdown 文件。
2. **Token 经济性读取策略（Avoid Full File Dumps）**：  
   * `00_承接链.md` 文件体量约 4.6 MB，`02_伏笔台账.md` 约 1.2 MB。**严禁在未指定行号的情况下尝试一次性全量读取这两个超大文件**，以免撑爆上下文窗口。
   * 必须使用针对性的行区间读取（`read_file` 的 `StartLine` 与 `EndLine`）或搜索定位。
3. **事实基准（Source of Truth）**：  
   在回答用户关于《大苍守夜人》的具体细节时，一律以本知识库中结构化归档的事实为准，严禁脑补或编造原文不存在的设定。专有名词以解析正文标注的“（原文如此）”为准。
